# 阶段 0 Review 清单

本阶段只确认产品和架构，不确认具体页面视觉，也不确认最终 CLI 参数。

## 建议你重点 Review

1. 产品主闭环是否符合助理真实工作：Baseline → Brief → 路线 → 大纲品牌审核 → 标题/正文/Tags 品牌审核 → 博主外部创作 → 最终归档 → 候选学习。
2. 是否接受“最终归档不会自动修改 Baseline”，而是先形成候选学习。
3. 是否接受 HTML 只读、反馈继续通过 Codex 对话完成。
4. 是否接受 MVP 只做小红书，并把同类博主分析放到主闭环之后。
5. 是否接受大纲和发布文案使用两条独立的品牌 Submission / Feedback / Approval 版本链。
6. 暂定产品名“小红书创作工作台”和 Skill 名 `xhs-creator-workbench` 是否需要调整。
7. 是否接受博主最终口播脚本由本人在系统外完成，工具只在发布后接回归档。

## Review 结论格式

你可以直接回复：

```text
阶段 0：通过，继续。
```

或者逐条反馈，例如：

```text
阶段 0：需要修改。
1. 对标分析要进入 MVP。
2. 大纲和发布文案需要合并为一次品牌审核。
3. 产品名改成……
```

在收到“通过，继续”之前，不进入阶段 1。
